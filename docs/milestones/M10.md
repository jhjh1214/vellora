# Milestone M10 — OCR (v0.10)

**Goal:** make scanned documents searchable and selectable, locally and offline. Tesseract 5 runs in its own sandboxed worker process, and its output becomes an **invisible text layer** in an appended content stream, saved incrementally, with the original page appearance untouched ([ADR-0010](../adr/0010-ocr-engine-tesseract.md)). Plan reference: [`PLAN.md` §C, §K](../PLAN.md) (phase 10). Estimated effort: 8–10 weeks.

**How to use this file:** the *one task per session* protocol in [`CLAUDE.md`](../../CLAUDE.md) and the [milestone rules](README.md#rules-for-every-milestone).

## M10 acceptance criteria

- [ ] OCR'd pages are searchable and selectable. Selection boxes align with the image words (median IoU ≥ 0.8). Pages render pixel-identically to before OCR.
- [ ] Character error rate on the synthetic ground-truth set ≤ 2% (English, clean 300 DPI) and ≤ 6% (noisy, skewed), with the `tessdata_best` English model.
- [ ] OCR runs in the background with progress and cancel, the UI stays within its frame-time budget, and a crash in the OCR worker never affects the document or the UI.
- [ ] Language packs: English and orientation detection are bundled. Others are downloaded only when the user asks, and verified by SHA-256 (decision #4).
- [ ] `vellora ocr` processes a 500-page scan at ≥ 20 pages/minute on the reference machine (4 workers).
- [ ] Tagged pre-release `v0.10.0`, only if the maintainer asks.

### - [ ] Task 2: OCR worker process
- **Do:**
  - New crate and binary `vellora-ocr`, with the same launch contract, framing and sandbox as the engine (ADR-0004/0015; the Windows, Linux and macOS sandboxes from M1/M6).
  - It receives a grayscale page image through a shared-memory region and returns words (text, box, confidence), lines, and page orientation/script (OSD).
  - Limits: image size and time per page; the hard deadline kills the worker.
- **Acceptance:** worker tests on fixtures. Negative sandbox tests. A crash or timeout gives a typed error, and the next page continues in a new worker.
- **Depends:** 1

### - [ ] Task 3: Page rasterisation and page analysis for OCR
- **Do:**
  - The engine renders pages for OCR at 300 DPI (configurable) to grayscale.
  - Classify each page: *has real text*, *image only*, *already has an invisible text layer*. Modes: `skip-text` (default), `force` (OCR all), `redo` (replace our earlier OCR layer, recognised by its marked content).
- **Acceptance:** classification tests on fixtures of each kind.
- **Depends:** 2

### - [ ] Task 4: Invisible text layer writer
- **Do:**
  - A **glyphless font** (Type0/CIDFontType2 whose glyphs have no outlines, plus a `ToUnicode` CMap) built by the `fonts` crate.
  - For each word: `Tr 3` text positioned at its box, with horizontal scaling (`Tz`) so the extracted word spans the image word, and rotation for skewed baselines.
  - Wrapped in marked content `/Span` with Vellora OCR properties (to support `redo`) in an appended stream; incremental save.
  - Page appearance unchanged.
- **Acceptance:** OCR'd fixtures: render pixel-identical; extracted text equals the OCR output; selection boxes align (IoU test).
- **Depends:** 3

### - [ ] Task 5: Orientation and deskew options
- **Do:** `FixOrientation` sets `/Rotate` from OSD (incremental, appearance as intended). `Deskew` applies a page content transform (flagged in `SaveImpact` as changing appearance). Both are off by default.
- **Acceptance:** tests with rotated and skewed fixtures.
- **Depends:** 4

### - [ ] Task 6: OCR in the UI
- **Do:**
  - Document → Recognise Text: page selection, languages, mode, options.
  - A background job panel with per-page progress, cancel and resume.
  - Result summary: pages processed, mean confidence, low-confidence pages with jump links.
  - When a document looks scanned (image-only pages), a non-modal "Make this document searchable" bar.
  - A worker pool sized from CPU cores and memory (default cores/2, max 4).
- **Acceptance:** Qt tests for the job lifecycle. Frame-time test during a 100-page OCR job.
- **Depends:** 4

### - [ ] Task 7: Language pack manager

- **Acceptance:** tests with a local HTTP fixture server: a hash mismatch is rejected; no network unless the user started the download.
