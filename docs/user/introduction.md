# Vellora user manual

Vellora is a desktop program for reading PDF documents. It runs on your computer, works on files on your computer, and needs no account and no network connection.

This manual describes what Vellora does today: opening, viewing, searching, copying text from and printing PDF files, looking at what a file contains, and the `vellora` command line. It does not describe plans.

- New here? Start with [Install](install.md) and [First steps](first-steps.md).
- Want to know what Vellora does with a file you do not trust? Read [Privacy](privacy.md) and [Security](security.md).
- The [keyboard shortcuts](shortcuts.md) page is written by the program itself, so it always lists the keys the program has.
