# Getting help

- **Questions and ideas:** GitHub Discussions (once enabled) or an issue using the *Feature request* template.
- **Bugs:** open an issue with the *Bug report* template.
- **A PDF that renders or behaves incorrectly:** use the *Compatibility report* template. Read its privacy note before attaching any document.
- **Security issues:** see [SECURITY.md](SECURITY.md). Never use public issues.

Vellora is pre-alpha; there is no end-user support yet.
